# 🩺 MediBot — Medical RAG Chatbot

MediBot is an AI-powered medical chatbot built using **RAG (Retrieval-Augmented Generation)**, **LangChain**, and **Streamlit**.

It retrieves relevant information from medical documents and uses an LLM to generate context-aware answers along with source documents.

## 🚀 Features

* Medical document-based Q&A
* RAG pipeline with vector search
* Hugging Face embeddings
* LLM-powered responses
* Source document retrieval
* Streamlit chatbot interface

## 🛠️ Tech Stack

**Python · LangChain · RAG · Hugging Face · Vector Database · Groq · Streamlit**
